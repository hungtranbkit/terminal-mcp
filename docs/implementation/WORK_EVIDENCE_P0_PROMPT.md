## 2. Hợp đồng dữ liệu chung, versioned và fail-closed
Giữ field state hiện tại tương thích ngược (SESSION_STATE: RUNNING/IDLE/WAITING_INPUT/OFFLINE/UNKNOWN...); bổ sung work_evidence (schema_version=1). Không đổi ngữ nghĩa state cũ ngầm.
- session_identity = node + backend + stable session/pane ID + session generation/creation timestamp. task identity = task_id/run_id/attempt_id khi tồn tại + dispatch generation; không invent ID; PID phải kèm start time/boot identity để tránh PID reuse. Bind bằng chứng đúng repo/worktree/branch/source HEAD khi đọc được. Mismatch generation/run/task/worktree: reject attribution, UNKNOWN. Không có task binding thì vẫn có thể báo hoạt động phiên nhưng không gán cho task.
- observed_at (UTC ISO8601), source_observed_at, last_verified_activity_at, freshness/age/TTL, reason_codes, coverage/availability per signal. Clock skew/reboot/reconnect/cache/duplicate/out-of-order/replay: không làm mới activity. Dùng monotonic để tính delta trong node, UTC để trình bày; server receive time không thay source time. TTL đề xuất 60s hoặc 2 sampling intervals, đo và cấu hình; không suy ra stuck chỉ vì mất telemetry.
- execution/work_state: DISPATCHED, CODING, TESTING, BUILDING, ANALYZING, REPORTING, WAITING, BLOCKED, IDLE, UNKNOWN. Có thể nhiều activity song song -> active_operations[]; primary_state theo precedence tài liệu, không che mất test nền của phiên IDLE. OFFLINE/STALE là health/freshness, không đồng nghĩa IDLE. Session RUNNING và execution UNKNOWN là kết quả hợp lệ.
- evidence[] gồm kind, provenance, observed_at, identity, bounded payload, evidence ID/fingerprint; phân biệt OBSERVER_VERIFIED (node/process/git/test runner), TOOL_EVENT (trusted adapter event có kết quả), SELF_REPORTED (stdout/chat/agent claim), UNAVAILABLE. Chỉ observer hoặc trusted tool event đã đối chiếu mới xác nhận work state/progress; agent không tự nâng cấp claim thành proof. evidence IDs phải truy hồi được; literal SHA256 64 hex, Git SHA đúng format/existence nếu claim đã commit, không placeholder.
- progress tách khỏi activity: source_delta (added/modified/deleted, loại file source/test/docs/generated/unknown), test_delta (suite/command label/start/end/exit/counts, commit hoặc dirty snapshot fingerprint), build_delta, commit_delta, gate_delta. Phân biệt local scratch, source worktree, committed, pushed, merged, deployed, runtime_verified. Mỗi event có timestamp và identity; event không mới thì không tăng tiến độ. source patch đã ghi không chứng minh vẫn đang code; test đã exit không phải TESTING. Gate % = số gate PASS đã xác minh / tổng gate required; không dùng elapsed, lines of code, CPU, số comment hay số commit làm %.

## 3. Node collector + controller: triển khai P0 thật
3.1. Audit existing node/backend/permission/queue contract, reproduce false positive bằng fixtures và runtime. Dùng process tree từ đúng pane/session/backend, read-only, giới hạn quyền/phạm vi. Linux ưu tiên /proc hoặc ps có argv kiểm soát; ghi PID/starttime, child tool type/phase, CPU time delta/I/O counters nếu có quyền, process alive; không scan process toàn host không cần thiết. Không gắn một PID từ node khác hay sibling session. Không lấy env, cmdline chứa secret; command label từ allowlist. macOS/Windows adapter dùng cơ chế sẵn có hoặc capability unavailable->UNKNOWN, không fake Linux data. tmux/herdr adapter phải giữ provenance.
3.2. Lấy 2 sample liên tiếp có identity khớp để chứng minh output/CPU/I/O/event delta. CPU cao hoặc process tên codex/claude tồn tại chỉ chứng minh activity chung, không chứng minh CODING. Spinner/redraw/ANSI/cursor/heartbeat/busy footer và terminal tail lặp là tín hiệu yếu. Khi log bị cắt, không đoán phần mất. Capture bounded (không đẩy raw terminal lên public), normalize control sequences, tránh hash churn do spinner, cache per generation TTL.
3.3. Thu source evidence trên registered allowed worktree: git status --porcelain=v1 -z (hoặc API sẵn có), name-status/diff-stat, HEAD, bounded source manifest/fingerprint/mtime. So snapshot trước/sau để phát hiện thay đổi kể cả uncommitted; không chỉ dùng dirty=true (dirty cũ không phải tiến độ). Không recurse toàn repo, không theo symlink ra allowed root, không đọc secrets/.env/.git objects/build outputs/log archives/node_modules/.venv; docs/report/evidence-only không tính sản phẩm coding. Phân loại source/test/docs/generated, không hardcode mọi repo extension; configurable allowlist/path policy, unknown nếu không chắc. Git read-only, safe argv shell=False, timeout, bounded files/bytes, no shell injection. Dùng task-owned explicit worktree binding, không tự suy từ cwd khi cwd là workspace root. Metadata không đọc được thì null+reason.
3.4. Tool execution: dùng trusted adapter lifecycle events nếu có (start/completion+argv class+PID+exit code), child process attribution, output/log new timestamp+delta. Test/build đang chạy cần process/active command đã xác minh và fresh heartbeat/output/CPU/I/O; test dài im lặng nhưng PID sống đúng identity và có tiến trình verified vẫn TESTING (last output riêng), nếu không chứng minh thì WAITING/UNKNOWN, không kill. Lệnh git/status/cat/sed/grep đọc source = ANALYZING nếu verified; gh comment, markdown/report writes = REPORTING; output kiểu 'PASS 1000 tests' không có verified exit/identity là unverified claim. Source write event hoặc diff delta đủ mới + activity bound mới CODING; nếu đã hoàn tất thì last_source_change + progress, current IDLE. Need input/quota/auth/dependency blocker = BLOCKED có reason; dispatch receipt = DISPATCHED trước execution. Một task blocked không giữ RUNNING vì session shell còn sống. Không suy diễn ANALYZING/REPORTING nếu chỉ nhìn footer.
3.5. Mở rộng existing authenticated inspect/read API (additive work_evidence), node protocol + controller pass-through và fleet snapshot/batch; no breaking existing clients. Bounded per-target sampling, TTL caching, rate limits, parallelism cap, error isolation, no busy polling, no new cross-node write, no second DB authority; nếu cần lưu vài sample/history thì dùng existing event/audit store hoặc bounded cache, privacy retention. Không thêm mandatory dependency hệ thống nặng. Trace observed/verified progress; old agent/missing version/401/timeout/clock skew -> UNKNOWN, legacy state chỉ hiển thị trạng thái phiên. Không refresh timestamp khi cache cũ. Unsupported nodes vẫn hoạt động cũ, không tự đẩy bản release fleet.
3.6. Security: đọc chỉ session/node/worktree có quyền; private API xem sanitized names/path/repo/SHA/metrics cần thiết. Không raw prompts, credentials, bearer, environment, arbitrary args, private path/source vào public snapshot/SSE/log. Public view chỉ enum, safe numeric counts/age, label allowlist hiện hữu; không lọc bằng regex rồi tin đoạn văn tùy ý, không expose SHA/path/private repo nếu policy cấm. Input untrusted, textContent/escaping, no HTML injection. Không chèn lệnh vào session RUNNING để lấy telemetry. Không tạo monitor session mới để thăm dò. Không tự resume, delete, reset hoặc force-kill từ telemetry.
